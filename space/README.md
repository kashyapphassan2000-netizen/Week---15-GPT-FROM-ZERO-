# gpt-from-zero Space

Type a prompt, get a completion from a 50M-parameter GPT trained from scratch.
Every output is machine-generated and factually meaningless. CPU inference is ~3-5 tok/s.

Set the `MODEL_REPO` Space variable to your model repo (e.g. `<hf-user>/gpt-from-zero`).
